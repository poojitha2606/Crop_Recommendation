🌱 Crop Recommendation System

A Machine Learning-based web application that recommends the most suitable crop based on soil nutrients and weather conditions.

Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit

Features
- Crop prediction using Machine Learning
- User-friendly Streamlit interface
- Real-time recommendations
